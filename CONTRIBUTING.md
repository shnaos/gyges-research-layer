# Contributing

Thanks for helping with Gyges Research Layer.

## Development workflow

1. Install dependencies: `npm install`
2. Run tests: `npm test`
3. Run type checks: `npm run typecheck`
4. Keep changes focused and privacy-first.

## Contribution principles

- Keep deny-by-default behavior intact.
- Avoid hidden network calls and telemetry.
- Document trade-offs and limitations honestly.
- Prefer simple, explicit APIs over implicit behavior.
